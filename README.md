# 856MO百貨

## 概要

856MO百貨（ハゴロモヒャッカ）は、
自分のファッションを気軽に投稿・閲覧するための超シンプルなファッションSNSです。

文章による自己表現やユーザー同士の濃い交流よりも、

- どんな服が投稿されているか
- 今どんなスタイルが人気なのか
- 自分の好みに近い服を探せるか

を重視します。

コンセプトは、

>　こちとらハイカラなファッションがみたいんやから、  
>　しょーもないDMとかフォローとかほんまにどーでもええ。  
>　ただ欲しいのは、ハヤリスタリとセンスだけやっちゅうねん。

です。

---

# サービス名

正式名称：

**856MO百貨**

読み：

**ハゴロモヒャッカ**

略称：

**856**

「856」は「ハゴロモ」の語呂合わせ。

ファッションSNSとして成長した場合、将来的には個人ブランドやクリエイターの商品を集約する
ショッピング機能を追加し、名前どおり本当の「百貨」となることを目標とします。

---

# 基本コンセプト

856は「人をフォローするSNS」ではなく、
**ファッションそのものを探すSNS**として設計します。

通常のSNSにありがちな、

- フォロー
- フォロワー
- ダイレクトメッセージ
- コメント
- プロフィール巡回

などの人間関係中心の機能は原則として実装しません。

代わりに、

- 新着投稿
- ハッシュタグ検索
- ランキング
- タグブックマーク
- リアクション

を中心に構成します。

---

# 投稿ルール

投稿できる内容は原則として以下のみです。

- 写真
- ハッシュタグ

長文キャプション機能はもたせない。
「服を見せる」ことを中心にするため、文章を書くことを利用者に要求しない設計。

---

# ユーザー

ユーザーは以下の情報を持ちます。

- ユーザー名
- メールアドレス
- パスワード

認証機能はDevise。

ユーザー名は、投稿者を特定する検索キーとして利用するため、ユニーク。

DB上ではユーザーIDで関連を管理し、画面上ではユーザー名を表示します。
